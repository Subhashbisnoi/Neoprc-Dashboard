**Neoprc Dashboard** is a modern, responsive web dashboard built with **React**, **TypeScript**, and **Tailwind CSS**. It provides dynamic data visualization, interactive UI components, and real-time analytics for monitoring key metrics.

---



## 🌟 Features

- **Interactive Charts & Graphs** – Dynamic data visualization components for metrics and KPIs.
- **Responsive Layout** – Fully responsive and mobile-friendly.
- **Reusable Components** – Clean, modular components for faster development.
- **Lightweight & Fast** – Built with Vite for quick dev feedback and fast production bundles.
- **Customizable Theme** – Tailwind makes it straightforward to customize look & feel.
- **Extensible** – Easy to wire up to any REST/websocket backend or static data.

---

## 🛠 Tech Stack

- **Frontend**: React + TypeScript  
- **Styling**: Tailwind CSS  
- **Build Tool**: Vite  
- **Bundler**: Vite (esbuild + rollup)  
- **Icons**: (e.g., Heroicons / lucide — add as needed)  
- **Charts**: (e.g., Recharts / Chart.js / ApexCharts — add as needed)
